# 던전의 놀이방

첫 화면에서 **카드 뒤집기** (`memory.html`) 또는 **카드 배틀** (`battle.html`)을 선택합니다.

## 카드 배틀

`cha` 폴더의 현재 캐릭터 22명을 사용합니다. 각 팀 1~4명을 편성하며, 적군에는 기존 몬스터 3종도 넣을 수 있습니다. 직업별 기본값에서 이름마다 고정된 무작위 보정(민첩/공격/방어 ±1, 체력 ±3, 마력 ±1)을 부여합니다. 궁수의 방어력 0은 유지합니다. 마력은 표시만 하며 스킬은 추후 추가합니다.

매 라운드 모든 생존 캐릭터가 민첩을 굴리고 낮은 결과부터 행동합니다. 동률은 무작위입니다. 아군은 현재 행동 캐릭터를 선택한 뒤 적을 지정하며, 적은 자동으로 대상을 선택합니다. 캐릭터마다 라운드당 한 차례 행동합니다.

공격자의 민첩 결과가 대상보다 3 이상 낮으면 연속공격합니다. 각 공격력은 새로 굴리고 방어는 첫 타격에서 한 번만 굴립니다. `피해 = max(0, 공격력 − 잔여 방어)`, `잔여 방어 = max(0, 잔여 방어 − 공격력)`입니다. 두 번째 공격은 남은 방어만 사용합니다. 다음 캐릭터의 별도 공격 행동에는 방어를 새로 굴립니다. 첫 타격에 사망하면 두 번째 타격은 생략하고, 사망자는 행동하지 못합니다. 모든 적을 섬멸하면 승리합니다.

`python sync_battle_data.py` 또는 `python build_site.py`가 이미지 폴더와 직업 데이터를 동기화합니다. GitHub Actions도 빌드할 때 동기화합니다. 새 캐릭터의 직업 배정은 스크립트의 JOBS에 추가합니다. 기존 몬스터 이미지와 공격·방어는 유지하며 개별 민첩·체력을 적용합니다. `node test_battle_engine.js`로 연속공격 예시, 방어 잔여량, 0 피해, 사망과 승패, 라운드 갱신, 인원 제한을 검증합니다.

## 카드 뒤집기

`start-game.bat`을 더블클릭하면 브라우저에서 게임이 열립니다. Python 3가 필요하며, 실행 중에는 서버 창을 열어두세요.

캐릭터는 `cha` 폴더에 넣습니다. PNG, JPG, JPEG, WebP, GIF, AVIF, SVG 파일을 지원합니다. 이름은 확장자를 제외한 파일명으로 표시합니다.

게임 시작을 누를 때마다 폴더를 다시 읽고 6 / 12 / 18 / 24종을 무작위 선택해 각각 두 장씩 만듭니다. 이미지가 부족한 쌍 수는 선택할 수 없습니다. 최소 6종이 필요합니다.

`index.html`을 직접 열면 마지막으로 생성된 `characters.js` 목록을 사용합니다. 준비 화면의 폴더 선택으로 최신 캐릭터를 읽을 수도 있습니다. 폴더 변경을 자동 반영하려면 `start-game.bat`으로 실행하세요.

## GitHub Pages 배포

저장소의 Settings → Pages → Source를 GitHub Actions로 설정합니다. main 브랜치에 업로드하면 `.github/workflows/pages.yml`이 `build_site.py`를 실행해 이미지 목록을 자동 생성하고 배포합니다. `cha` 폴더의 이미지를 추가·삭제·변경한 뒤 main에 업로드하면 사이트에도 반영됩니다.

수동 정적 배포는 `python build_site.py`를 실행한 뒤 `_site` 폴더의 내용만 호스팅에 올리면 됩니다. 배포된 게임은 같은 경로의 `characters.json` 목록을 사용합니다.
